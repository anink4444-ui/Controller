# Kyuubi DualSense – GamepadViewer / OBS

## 1. GitHub hochladen
Erstelle ein öffentliches GitHub-Repository, z. B. `kyuubi-dualsense-overlay`, und lade den kompletten Inhalt dieses Ordners hoch. Die Struktur muss so bleiben:

- `edit.css`
- `assets/controller.png`

Aktiviere danach unter **Settings → Pages** GitHub Pages für den Branch `main` und Ordner `/ (root)`.

## 2. GamepadViewer-Link
Wenn dein GitHub-Benutzername z. B. `DEINNAME` und das Repository `kyuubi-dualsense-overlay` heißt, lautet die CSS-Adresse:

`https://DEINNAME.github.io/kyuubi-dualsense-overlay/edit.css`

Der GamepadViewer-Link ist dann:

`https://gamepadviewer.com/?p=1&s=5&editcss=https%3A%2F%2FDEINNAME.github.io%2Fkyuubi-dualsense-overlay%2Fedit.css`

## 3. OBS
Browser-Quelle hinzufügen und den GamepadViewer-Link einfügen. Starte mit **749 × 635 px**. Hintergrund ist transparent.

## Hinweise
- Die Sticks werden weiterhin von GamepadViewer bewegt.
- Face Buttons, D-Pad, L1/R1 und L2/R2 bekommen beim Drücken eine orange Fläche statt eines zusätzlichen Kreises.
- Falls dein DualSense-D-Pad nicht korrekt gemappt wird, kann DS4Windows bzw. eine GamepadViewer-Tastenbelegung nötig sein.
